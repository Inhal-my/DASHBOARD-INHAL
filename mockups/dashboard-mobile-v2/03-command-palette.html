Command palette — satu kotak untuk semua

Tekan tombol cari (atau ikon kaca pembesar) lalu langsung mengetik. Hasil dari berbagai jenis digabung dan dikelompokkan: Blok, Kegiatan, dan Mahasiswa. Ketuk hasil kegiatan untuk langsung membuka form BA. Gaya ini lahir dari pola "command palette" di aplikasi desktop seperti Linear/Notion.

Cocok karenaPaling cepat untuk admin mahir; satu jalur untuk cari apa pun; tidak perlu tahu struktur menu.
Perlu diperhatikanBergantung pada kualitas pencocokan teks; di HP tanpa keyboard fisik, kombinasi tombol perintah tidak relevan (pakai ikon).
